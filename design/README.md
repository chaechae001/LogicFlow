# LogicFlow 서비스·UX 설계

논리적 사고를 시작하고 이어가는 과정의 마찰을 줄이기 위한 퍼널·정보 구조·화면 시안입니다.

## 설계 관점

- 연습 문제 선택에서 첫 작성까지 필요한 결정을 줄입니다.
- 자유 작성과 구조화 질문을 함께 제공해 시작의 부담을 낮춥니다.
- 사실·해석·가설 등 내용의 의미를 시각적으로 구분합니다.
- 단계마다 사고 구조가 드러나는 도식을 제공합니다.
- 사고 과정 기록과 외부에 전달할 결과물의 목적을 구분합니다.
