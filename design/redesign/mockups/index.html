Think Flow 화면 설계

논리적 사고 훈련 서비스의 처음부터 다시 만든 화면 시안입니다. 기존 폴더의 구조·디자인은 참고하지 않았습니다. 서비스명은 Think Flow로 확정했습니다.

화면
01

랜딩

히어로에 제품의 실제 동작을 그대로 넣었습니다. 한 줄 문제 정의가 로직 트리로 갈라지고, 근거 없는 가지에 주의 표시가 붙습니다.

열기 → 03

작업 화면

핵심 화면입니다. 질문을 한 번에 하나만 보여주고, 답한 만큼 아래 도식이 자랍니다. 10단계 인포그래픽을 전부 만들었습니다 — 왼쪽 레일에서 단계를 눌러 확인하세요.

관찰 저장소와 질문 저장소. 두 줄 캡처로 던져두고, 자주 적은 것부터 문제로 키웁니다. 사고 케이스 목록도 여기 있습니다.

카테고리 색 — 탐색·선택 화면 전용

메뉴가 전부 같은 색이라 구분이 안 되던 문제를 세 개의 독립된 체계로 나눴습니다. 의미 태그와는 모양이 다르고(알약 vs 색 막대) 쓰이는 화면도 다릅니다. 같은 자리에 함께 나오지 않습니다.

훈련 계열 — 10단계를 네 묶음으로

정의 · 01–03 구조 · 04 검증 · 05–07 표현 · 08–10

참고 자료의 “문제 정의 → 구조화·가설 → 근거 기반 의사결정 → 글·말·포트폴리오 표현” 네 훈련을 그대로 색으로 옮겼습니다.

난이도 — 색과 개수를 함께

입문 기본 심화 도전

난이도는 순서가 있는 값이라 색만으로 두지 않고 채워진 막대 개수로도 읽히게 했습니다. 색맹이어도 구분됩니다.

산업 — 주제를 고를 때

커머스핀테크콘텐츠·OTT B2B SaaS플랫폼·O2OHR·교육

문제 유형(전환율 하락, 지표 설계 등)은 색을 주지 않고 회색 칩으로 둡니다. 축을 셋으로 제한해야 화면이 무지개가 되지 않습니다.

난이도모듈 카드, 케이스 목록색 + 막대 개수입문 → 도전 (순서 있음)
산업주제 선택, 케이스 목록왼쪽 색 막대6종
주색 스틸 블루버튼, 활성 상태, 링크면 채움—
주의 테라코타논리 공백, 코치 지적테두리 + 옅은 배경—

한 화면에 색 체계는 최대 두 개만 등장합니다. 작업 화면에는 의미 태그 + 훈련 계열, 시작 화면에는 훈련 계열 + 난이도 + 산업이 나오고 의미 태그는 나오지 않습니다.
