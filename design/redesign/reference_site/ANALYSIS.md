# 레퍼런스 분석 — DACON 데이스쿨 · 프로그래머스

> 실제 캡처(PDF 18종)를 이미지로 렌더링해 색감·레이아웃·구조·플로우를 분석함.
> 목적: Logic Flow(논리적 사고 훈련 서비스)에 적용할 인사이트 도출.

---

## 한눈에 보는 결론

두 서비스 모두 **순백색(#FFFFFF) 배경 + 블루 단일 포인트 컬러**를 씁니다.
UI 자체는 무채색+블루로 절제하고, **색의 다양성은 "콘텐츠 카드 썸네일"에서만** 나옵니다.
→ v3 웜그레이(어두운 톤)가 무거웠던 문제의 정답이 여기 있습니다: **배경을 흰색으로, 포인트는 블루 하나로.**

학습 화면은 둘 다 **좌우 2단(이론/설명 ↔ 실습/입력) + 사이드바(진도·코치)** 구조이고,
학습 단위는 **스테이지 → 3단계(이론→실습→퀴즈)**로 잘게 쪼개져 있습니다.
→ Logic Flow의 "질문 → 작성 → 도식" 3단 구조와 정확히 대응됩니다.

## 1. DACON 데이스쿨

### 1-1. 서비스 구조
```
데이스쿨(학습 허브)
├─ 러닝코스 (8)     — 맞춤형 학습 경로 큐레이션
├─ 트랙 (6)         — 이론+해커톤 통합, 기수제(2026-S2)
├─ 첫걸음 (27)      — 입문
├─ 딥러닝 (20)      — 심화 실습
├─ 중점학습 (22)    — 역량 강화
├─ 프로젝트 (33)    — 입문10/초급17/중급6
├─ 랭커특강 (40)    — 동영상
└─ 해커톤 (57)      — 최종 실전 대회
```
지표를 상단에 노출: **학습자 55,376명 · 학습시간 320,258분 · 콘텐츠 299개**

### 1-2. 학습 FLOW
```
첫걸음 → 프로젝트(입문→초급→중급) → 해커톤
         ↕ XP·레벨 시스템이 전 과정을 관통
로드맵(입문→초급→중급)으로 여정을 한 장에 시각화
```

### 1-3. 화면별 분석

**[데이스쿨 메인]** — 카드 그리드 허브
- 섹션마다 `제목 + 개수(8개) + 한 줄 설명` → 카드 그리드
- 카드: 상단 `N명 참여중` 배지 / 그라데이션 썸네일 + 계열 태그(SQL·LLM·ML) / 하단 제목 + 키워드 태그 + `N Stages` + 학습상태
- **계열별 썸네일 색 구분**이 핵심 — SQL=오렌지, LLM=블루, 트랙=스카이블루, 딥러닝=코랄
- `더보기 (12/27)` 페이지네이션, 섹션 이모지(🍼 첫걸음, 🐡 딥러닝)

**[학습 상세 — SQL 입문]** — 좌우 2단 + 사이드바
- 헤더: 제목 + 부제(SELECT, WHERE...) + 메타(🏳첫걸음 ⏱3시간 <>16스테이지 👥441명)
- 왼쪽(넓음): 프로젝트 설명, 선행 학습 시리즈(1→2 연결 카드), "무엇을 다루나요?", "이번 교재에서 배워요"
- 오른쪽 사이드바:
  - `내 학습 진도` 카드 — 현재 스테이지 + `이어서 학습하기` 버튼
  - `데이스쿨 캐릭터` 카드 — 얼굴 일러스트 + 격려 메시지 + 문의
- 명시된 학습 설계: **"이론 → 실습 → 퀴즈 3단계 구조. 개념 이해 후 Jupyter에서 직접 실행, 퀴즈로 스스로 점검"**

**[학습 워크스페이스 — SELECT와 AS]** ★ Logic Flow와 직결
- 좌측 세로 **스테이지 네비게이터**(소개·1·2·3·4, 원형 번호, 현재 활성)
- 왼쪽 패널(이론): 소제목 + 설명 + 코드 블록(monospace, 회색 배경, 화살표 도식) + 하단 `풀이` 아코디언
- 오른쪽 패널(실습): 코드 에디터 툴바(실행▶ 정지■ 새로고침↻) + `☀Light` + 질문 리스트(현재 항목 박스 강조)
- 학습 시 `XP를 획득했어요!` 토스트

**[로드맵]** — 학습 여정 한 장
- `입문 → 초급 → 중급` 3열, 각 열에 트랙 세로 나열, **점선 화살표로 연결**
- 파란색 단색, 극도로 미니멀

**[트랙 상세]**
- 탭: 안내 / 리더보드 / Q&A / 트랙 결과
- 커리큘럼 카드 그리드(`0% 진행` 배지 + 번호) + 우측 스티키 `목차`(트랙·개요·규칙·일정·리워드)
- `0% 완료` 진행률

### 1-4. 색감 (실측 근사)
| 역할 | 값 |
|---|---|
| 배경 | `#FFFFFF` 순백색 |
| 주색(로고·링크·강조 숫자) | 코발트 블루 `#2E6FF2`~`#3B82F6` |
| 본문 텍스트 | `#1A1A2E` / 보조 `#6B7280` |
| 계열 썸네일 | 오렌지 `#F5A623` · 블루 · 스카이 · 코랄·핑크 그라데이션 |
- UI는 흰색+블루로 절제, 색은 카드 썸네일에서만. 테두리 얇은 회색, 여백 넉넉.

## 2. 프로그래머스

### 2-1. 서비스 구조
```
프로그래머스
├─ AI 역량평가      — 기업/응시자 진단
├─ 교육(스쿨)       — 강의, MY 스쿨
├─ 데브코스/부트캠프 — 국비지원 커리어 과정
├─ 코딩테스트        — 문제은행(알고리즘·SQL·기초)
├─ 스킬체크·과제테스트
└─ 인증시험·리눅스 자격증
```

### 2-2. 학습 FLOW
```
강의(이론) → 코딩테스트 문제 풀이 → 스킬체크(진단) → 인증
             ↑ 브라우저 내장 코드 에디터에서 즉시 실행·채점
```

### 2-3. 화면별 분석

**[메인]**
- 헤더: 로고 + 메뉴(AI역량평가·교육·데브코스·코딩테스트·인증시험·리눅스) + 블로그·기업서비스·🔔·프로필
- 히어로: 좌측 카피 + 우측 **민트색 일러스트 배너**(캐러셀)
- **퀵 아이콘 메뉴 6개**: 무료 국비 강의 / 코딩테스트 문제 / 수강 중인 강의 / 블로그 / 스킬체크 / 코딩역량인증시험
- 코스 카드 그리드(3열): 썸네일 + 제목 + `모집 중`·`국비지원`·`D-16` 태그 + 할인가(90% 빨강 강조)

**[코딩테스트 목록]** — 테이블 + 사이드바
- 상단 검색바 + 필터(상태·난이도·언어·기출 드롭다운)
- `547 문제` + 정렬. 테이블: 상태(✓) | 제목+분류 | 난이도(`Lv.0` 파란 배지) | 완료한 사람 | 정답률
- 우측 사이드바: 프로필 카드(순위·점수·해결수) / `추천 코스`(강의 썸네일) / 활동기록 프로모
- 페이지네이션

**[문제 풀이 화면]** ★ Logic Flow와 직결
- 상단 바: 🔖문제명 | `제출 내역` 탭 | `Python3` 드롭다운 | ⚙
- 문제 설명 + **컬러 격자로 문제 시각화**(공원 돗자리를 A/B/D/E/F 색 블록으로) ← 텍스트 문제를 그림으로
- 변수는 인라인 코드 하이라이트(`mats`, `park`), 제한사항은 중첩 불릿
- (좌: 문제 / 우: 코드 에디터 2단 분할 구조)

**[강의 상세]**
- 제목 + 관련 키워드 태그(JavaScript·HTML·CSS)
- `도서와 함께 들으면 좋은 강의` 안내 박스(파란 테두리)
- 친근한 Q&A 카피("진짜 처음이라 실수 많을텐데")
- 보라색 일러스트 배너(`5분 동영상 53개 + 코딩 실습 22개`)

### 2-4. 색감 (실측 근사)
| 역할 | 값 |
|---|---|
| 배경 | `#FFFFFF` 순백색 |
| 주색(배지·링크·체크) | 블루 `#3B82F6` (로고는 다크) |
| 히어로 포인트 | 민트 `#C7F0D8` |
| 본문 | `#212121` / 회색 보조 |
| 강조(할인) | 레드 |
- 밝고 깔끔. 콘텐츠 썸네일·문제 시각화로 색 다양성. 코드는 회색 인라인.

## 3. Logic Flow 적용 인사이트

### 3-1. 색감 (v3 문제 해결)
1. **배경을 순백색 `#FFFFFF`으로.** 웜그레이(#F6F4F1) 어두운 톤 폐기 → 두 레퍼런스 모두 흰색.
2. **포인트 컬러는 블루 하나.** 딥블루보다 밝은 코발트/스카이(`#2E6FF2`~`#3B82F6`)로 가볍게.
3. **색 다양성은 UI가 아니라 "콘텐츠"에서.** 4계열(정의·구조·검증·표현)을 카드 썸네일 그라데이션으로 구분 — UI 크롬은 흰색+블루+회색으로 절제.
4. 테두리는 얇은 회색, 여백 넉넉, 그림자 최소. → "차분하고 읽기 쉬운" 학습 톤.

### 3-2. 레이아웃
5. **워크스페이스 = 좌우 2단 + 좌측 스테이지 네비 + 우측 진도 사이드바.**
   - 좌측 세로 스텝 네비(1~10 원형 번호, 현재 활성)
   - 왼쪽 패널: 질문·이론·설명 / 오른쪽 패널: 작성·도식(실습에 해당)
   - 우측 사이드바: `내 진도` + `이어서` 버튼 + `코치 캐릭터` 카드
6. **허브/시작 화면 = 카드 그리드.** 섹션마다 `제목 + 개수 + 한 줄 설명` → 카드(참여 배지·계열 썸네일·태그·단계수·상태).

### 3-3. 학습 구조·플로우
7. **스텝을 3단계로 쪼갠다: 질문 → 작성 → 도식** (DACON의 이론→실습→퀴즈와 동형). 한 스텝 안에서도 마이크로 스테이지로 분할.
8. **로드맵을 한 장으로.** 일일→주간→월간(또는 정의→구조→검증→표현)을 점선 화살표 여정으로.
9. **진행률을 눈에 보이게.** XP·`N Stages`·`0% 완료`처럼 스텝 완료·케이스 진도를 배지/바로.
10. **여정 끝에 실전.** DACON은 해커톤, 프로그래머스는 인증 — Logic Flow는 "포트폴리오/커뮤니티 공유"가 그 자리.

### 3-4. 디테일
11. **텍스트를 그림으로.** 프로그래머스가 문제를 컬러 격자로 시각화하듯, Logic Flow는 사고 단계를 인포그래픽으로(이미 방향 일치).
12. **캐릭터 코치 + 친근한 카피.** 데이스쿨 캐릭터·프로그래머스 Q&A 톤처럼, 코치를 인격화하고 마이크로카피를 따뜻하게.
13. **사이드바 추천.** "다음 추천 스텝/케이스"를 사이드바에 상시 노출.
