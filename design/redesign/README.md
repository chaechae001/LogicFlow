## 색 체계 요약

색이 많으면 무지개가 되고 적으면 구분이 안 되므로, **체계를 다섯으로 나누고 쓰이는 자리를 고정**했습니다.

| 체계 | 어디에 | 모양 | 축 |
| --- | --- | --- | --- |
| 의미 태그 | 작업 화면 안의 **내용** | 알약 + 점 | 사실 · 해석 · 가설 · 근거 · 미확인 · 공백 |
| 훈련 계열 | 시작 화면, 단계 레일 | 왼쪽 색 막대 | 정의 · 구조 · 검증 · 표현 |
| 난이도 | 모듈 카드, 케이스 목록 | 색 + **막대 개수** | 입문 → 도전 |
| 산업 | 주제 선택, 케이스 목록 | 왼쪽 색 막대 | 6종 |
| 주색 / 주의색 | 버튼·활성 / 논리 공백 | 면 채움 / 테두리 | 스틸 블루 `#2A5A87` / 테라코타 `#B05A3C` |

**한 화면에 색 체계는 최대 두 개**만 등장합니다. 의미 태그와 카테고리는 모양이 다르므로(알약 vs 왼쪽 막대) 색이 겹쳐도 혼동되지 않습니다.

## 설계의 핵심 판단

**1. 질문을 한 번에 하나만 보여준다**
빈 텍스트 상자가 막막함의 원인입니다. `질문 → 선택지 → 문장 조립기 → 도식 빌더` 순으로 마찰을 낮췄습니다.

**2. 단계마다 그려지는 그림이 다르다**
맥락 카드 · 사실/해석 보드 · 조립 바 · 로직 트리 · 가설 덱 · 검증 매트릭스 · 비교 스코어 · FLOW 체인 · 지표 카드 · 논리 체인. 답할 때마다 즉시 갱신되고 별도 생성 버튼이 없습니다.

**3. 화면을 5개로 줄였다**
랜딩 · 시작 · 작업 · 저장소 · 결과물.

**4. 주의색은 논리 공백에만 쓴다**
화면에서 유일한 유채색 강조이고, "여기 근거가 없다"는 신호 전용입니다.

**5. 템플릿이 단계 수를 정한다**
단계는 10개 고정, 템플릿이 부분집합을 켭니다. 1단계짜리와 10단계짜리가 같은 엔진에서 돕니다.
