후보 A · B 비교

색감·디자인은 v2(밝은 청회색 + 스틸블루), 서체·굵기·기능은 v3(Pretendard·커뮤니티) 기준으로 통일했습니다. 두 후보의 차이는 작업 화면(워크스페이스)에 있습니다. 나머지 페이지는 공통입니다.

두 후보 공통 — 이번에 반영한 요청
  • 제목·소제목 절반으로 축소, 소제목 1줄
  • 자유 작성 / 질문 따라가기 순서로 변경
  • 좌·중·우 스크롤해도 고정(sticky)
  • 좌측 라벨 굵기 강화
  • 예시·코치·저장소에 ‘도식화’ 연습장 추가
  • 좌·우 패널 접기/펴기 토글
  • 사고 흐름(현재 단계) 항상 표시
  • 커뮤니티 등 v3 기능·네비 반영
  • 항목 미리 채우지 않음 · 예시는 토글
후보 A

v2 정제 — 질문·도식 병행

기존 v2 워크스페이스 구조를 그대로 유지하면서 요청사항만 반영했습니다. 단계별 질문 카드와 인포그래픽이 중심입니다.

  • 좌 10단계 사고 흐름 레일(항상 고정)
  • 중 컴팩트 헤더 + 질문/자유작성 + 단계별 도식(트리·매트릭스·스코어)
  • 우 예시 · 코치 · 저장소 · 도식화 탭
  • 익숙하고 안정적. 10단계가 모두 채워져 있어 흐름 파악이 쉬움

후보 B

안 3 · 구조 아웃라인

좌측 아웃라인이 사고 전체의 뼈대가 됩니다. 지금 쓰는 내용이 논리 어디에 속하는지 항상 보이도록 재설계했습니다.

  • 좌 살아있는 사고 아웃라인(단계 → 항목 계층, 직접 추가)
  • 중 선택한 노드에 대해 빈 작성 + 예시 토글(기본 숨김)
  • 우 구조 점검(MECE) · 코치 · 저장소 · 도식화 탭
  • 구조화·논리정연에 강함. 누락·중복을 스스로 발견하기 좋음
