# 03. Lean PRD

## 문제

AI 사용자는 빠르게 산출물을 만들 수 있지만, 문제 정의·가설·검증·판단의 사고 과정을 직접 수행하고 축적하기 어렵다.

## 해결 가설

사용자가 자신의 생각을 먼저 작성한 뒤 단계별 질문, 논리 구조화, AI 피드백, 회고를 반복하고 그 변화가 기록되면 논리적 사고법을 점차 내재화할 수 있다.

## 핵심 객체: Thinking Case

하나의 문제에 대해 사용자가 관찰, 문제 정의, 구조화, 가설, 검증, 대안, 판단, 실행, 회고를 수행한 전체 기록.

## P0 기능

1. Practice Case 선택
2. Thinking Case 생성
3. 8단계 Guided Workspace
4. 자동 저장과 재개
5. Response Version
6. Hypothesis Card
7. Validation Matrix
8. Alternative Decision Matrix
9. Action Plan
10. Logic Flow
11. Case Report
12. Portfolio Preview

## P1 기능

- AI Coach Mock 및 실제 API
- Rubric
- Growth Flow
- My Case 인터뷰
- AI Scenario
- Case Database 필터

## 제외 범위

- 자동 통계 분석
- 자동 머신러닝

- 결제
- 커뮤니티

- 모바일 앱

- 기업 관리자 페이지

## 주요 지표

### Funnel
- Case 시작률
- Step 2 진입률
- 문제 정의 완료율
- 전체 Case 완료율
- Report 생성률
- Portfolio Preview 생성률

### 사고 행동
- 사실·해석 분리율
- 가설 4개 이상 작성률
- 대안 가설 작성률
- 기각 조건 작성률
- 검증 지표 작성률
- 성공·수정·중단 기준 작성률
- 최초·최종 판단 비교 완료율

### 장기 학습
- AI 도움 없이 완료한 단계 수
- 반복 약점 감소
- 다른 도메인으로 프레임워크 전이
- 최초 Case와 최근 Case의 루브릭 변화
