# 05. Guided Thinking Flow Specification

## 공통 Workspace

왼쪽: 단계 내비게이션  
가운데: 사용자 작성 영역  
오른쪽: AI Coach  
하단: 이전 / 저장 / AI 점검 / Flow / 단계 완료 / 다음

AI 패널은 사용자 입력 전 답안 생성 기능을 제공하지 않는다.

---

## Step 1. 사실·해석 분리

### 학습 목표
사실, 해석, 가설, 해결 아이디어, 모르는 것을 구분한다.

### 필수 입력
- 확인된 사실 2개 이상
- 나의 해석
- 검증되지 않은 가설 2개 이상
- 떠오른 해결 아이디어
- 아직 모르는 것

### UI
다섯 개 카드. 문장 드래그 이동 지원.

### AI 개입
- 사실에 추정 표현 포함
- 해결안이 사실보다 먼저 구체화
- 하나의 원인만 존재

### 완료
“현재 확인된 것은 __이고, 나는 __라고 해석한다. 하지만 __는 아직 검증되지 않았다.”

---

## Step 2. 문제 정의

### 학습 목표
사용자·상황·목표·어려움·영향을 포함한 문제를 작성한다.

### 필수 입력
- 대상 사용자
- 상황
- 사용자 목표
- 구체적 어려움
- 사용자/서비스 영향
- 미검증 가정
- 핵심 질문 2개

### 조립 형식
`[대상]이 [상황]에서 [목표]를 하려 할 때 [어려움]을 겪어 [영향]이 발생할 가능성이 있다.`

### AI 개입
- 대상이 너무 넓음
- 기능 부재를 문제로 표현
- 원인·결과 단정
- 영향이 추상적

---

## Step 3. 고객 여정 구조화

### 학습 목표
문제를 채널 이동의 전체 과정에서 찾는다.

### Primary Framework
Customer Journey Map

### 단계별 필드
- 사용자 행동
- 목표
- 접점
- 필요한 정보
- 감정
- 마찰
- 확인 데이터
- 심각도
- 근거 수준

### 보조 구조
MECE Issue Tree

### 완료
- Journey 6단계 이상
- 마찰 3개 이상
- 문제 그룹 3~5개
- 우선 확인 지점 1개와 이유

---

## Step 4. 원인 가설

### 학습 목표
복수 원인을 검증 가능한 문장으로 바꾼다.

### 카드 필드
- 가설 문장
- 연결 Journey 단계
- 이유
- 맞을 때 예상 행동
- 틀릴 때 예상 행동
- 필요 데이터
- 지표
- 기각 조건
- 확신 수준

### 완료
- 4개 이상
- 서로 다른 범주 3개 이상
- 대안 가설 1개 이상
- 모든 가설에 기각 조건

---

## Step 5. 검증 설계

### 학습 목표
가설과 증거를 연결한다.

### Matrix
- 가설
- 검증 질문
- 데이터
- 수집 방법
- 핵심 지표
- 지지 기준
- 기각 기준
- 한계
- 접근 가능성

### 완료
- 가설마다 검증 1개 이상
- 정량·정성 방법 포함
- 기준과 한계 작성
- 내부 데이터가 없을 때 대체 검증

---

## Step 6. 대안 비교

### 학습 목표
처음 아이디어를 정답으로 고정하지 않는다.

### 대안 카드
- 대안
- 대응 가설
- 사용자 가치
- 내용
- 효과
- 자원
- 난이도
- 검증 난이도
- 위험
- 개인정보·운영 고려

### Decision Matrix
기준별 가중치와 근거를 사용자가 입력한다.

### 완료
- 대안 3개 이상
- 공통 기준 4개 이상
- 선택안
- 선택하지 않은 이유
- 판단을 바꿀 조건

---

## Step 7. Action Plan

### 학습 목표
가장 불확실한 가설을 작은 행동으로 검증한다.

### 필드
- 검증 가설
- 실행 행동
- 대상
- 범위
- 프로토타입
- 비교 조건
- 지표
- 성공 기준
- 수정 기준
- 중단 기준
- 다음 결정

### 완료
한 개의 실행 가능한 실험과 후속 의사결정이 존재한다.

---

## Step 8. 결론·회고

### 필수 결과
- Top Message
- 핵심 근거 3개
- SCQA
- 최종 Action
- 남은 불확실성
- 회고
- 공개 가능한 Portfolio 요소

### 회고 질문
- 처음 원인은 무엇이라 생각했는가
- 약해진 가설은 무엇인가
- 생각을 바꾼 질문은 무엇인가
- 해결책을 너무 빨리 선택했는가
- 아직 검증되지 않은 것은 무엇인가
- 다른 서비스에 전이 가능한 원리는 무엇인가
