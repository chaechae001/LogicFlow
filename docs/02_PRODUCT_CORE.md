# 02. Product Core Definition

## 제품 한 문장 정의

AI를 활용하는 사람이 자신의 생각을 직접 꺼내고, 문제 정의–구조화–가설–검증–의사결정–실행의 과정을 반복적으로 훈련하며, 그 사고 과정과 성장 기록을 리포트와 포트폴리오로 전환하는 학습 플랫폼.

## 1차 사용자

AI를 자주 활용하지만 자신의 논리적 사고력과 문제해결력을 키워 프로젝트와 포트폴리오로 증명하고 싶은 취업준비생·직무 전환자.

## 핵심 가치 제안

- AI가 생각을 대신하지 않는다.
- 사용자의 첫 답변 이후에만 개입한다.
- 정답보다 논리 공백을 알려준다.
- 틀린 가설과 수정 이력을 보존한다.
- 반복할수록 도움을 줄인다.
- 동일한 Thinking Case를 리포트·블로그·포트폴리오로 재사용한다.

## MVP 단일 핵심 경험

사용자가 막연한 생각 또는 준비된 Practice Case를 선택하고, 목적·맥락 이해부터 결론 전달·회고까지 10단계 사고 Flow를 직접 수행해 근거 있는 실행안이 포함된 Thinking Case를 완성한다. 각 단계에서는 자유 작성과 구조화 입력 중 하나를 선택할 수 있으며, 방식을 전환해도 기존 작성 내용은 보존한다.

Practice Case를 선택한 사용자는 문제와 업무 요청을 확인한 뒤 사전 답변 없이 Case를 생성한다. 첫 생각은 `목적·맥락 이해` 단계 안에서 작성하며, 문제 정의 전에 해결안을 필수로 요구하지 않는다.

## 시작 방식

### A. Guided Practice
이미 구성된 실무 문제를 해결한다.

### B. My Case
AI 인터뷰를 통해 사용자의 실제 업무 문제를 구체화한다.

### C. AI Scenario
업무 분야, 난이도, 훈련 역량에 맞는 가상 현업 문제를 생성한다.

MVP의 첫 Vertical Slice는 `Guided Practice`와 올리브영 대표 Case에 집중한다.

## 사용자와 AI의 역할

| 활동 | 사용자 | AI |
|---|---|---|
| 최초 생각 | 직접 작성 | 개입하지 않음 |
| 문제 정의 | 초안 작성 | 모호함·가정 질문 |
| 구조화 | 기준 선택 | 중복·누락 점검 |
| 가설 | 직접 작성 | 대안·반례 질문 |
| 검증 | 지표·기준 작성 | 측정 가능성 점검 |
| 대안 비교 | 기준·가중치 결정 | 편향 점검 |
| 판단 | 사용자가 결정 | 불확실성 확인 |
| 보고서 | 공개 내용 선택 | 구조화 지원 |

## 도움 수준

- Guide
- Coach
- Challenge
- Independent

## MVP 성공 기준

사용자가 샘플 답안 없이 Case를 작성하고, 브라우저를 닫았다가 다시 접속해 이어서 작성하며, 마지막에 Logic Flow와 Case Report를 확인할 수 있다.
