# 04. Representative Practice Case — Olive Young O2O

## Case 제목

오프라인 상품 체험을 앱 구매 여정으로 연결하는 올리브영 O2O 서비스 개선

## 주의

이 Case는 공개 정보와 사용자 가정을 기반으로 설계한 가상 현업형 연습 문제다. 올리브영 내부 데이터나 실제 고객 행동을 확인한 결과로 표현하지 않는다.

## 역할

올리브영 서비스 기획자 또는 데이터 기반 Product Manager.

## 업무 요청

오프라인 매장에서 상품을 체험한 고객이 앱에서 해당 상품과 옵션을 다시 찾고, 리뷰·혜택·재고·배송 정보를 확인해 구매 결정을 이어가는 과정의 단절 가능성을 정의한다. 원인 가설, 필요한 데이터, 검증 방법, 우선 개선안과 Action Plan을 제안한다.

## 최초 제공 상황

올리브영 고객은 오프라인 매장에서 상품을 직접 체험하고, 앱에서는 상품 정보·리뷰·재고·혜택·구매 기능을 이용할 수 있다. 그러나 오프라인 경험을 앱에서 이어가는 과정에는 여러 단계가 존재한다.

## 핵심 문제 정의 초안

오프라인 매장에서 상품을 체험한 뒤 구매 여부를 추가로 검토하려는 고객이, 매장에서 확인한 상품과 옵션을 앱에서 다시 찾고 관련 리뷰·혜택·재고 정보를 연결해 확인하는 과정에서 반복적인 탐색을 거치며 올리브영 채널 안에서 구매 결정을 이어가는 데 어려움을 겪을 가능성이 있다.

## 고객 여정

```text
매장 방문
→ 상품 발견
→ 테스트·상담
→ 상품 기억·저장
→ 앱 진입
→ 상품 재탐색
→ 리뷰·혜택 비교
→ 재고·배송 확인
→ 구매 판단
→ 결제·수령
```

## Issue Tree

```text
O2O 구매 여정 단절
├─ 상품 식별
│  ├─ 상품명 기억
│  ├─ 색상·호수·옵션 구분
│  └─ 매장 상품과 앱 상품 연결
├─ 앱 재탐색
│  ├─ 정확한 검색어 의존
│  ├─ 유사 상품 다수
│  └─ 체험 상품 기록 부재
├─ 의사결정 정보
│  ├─ 체험과 리뷰 분리
│  ├─ 개인 관련성이 낮은 리뷰
│  └─ 혜택·가격 재비교
├─ 구매 실행
│  ├─ 재고
│  ├─ 배송·픽업
│  └─ 구매 시급성
└─ 외부 요인
   ├─ 타 채널 가격
   ├─ 브랜드 자사몰
   └─ 구매 필요성
```

## 핵심 가설

### H1 상품 재식별
매장에서 체험한 상품과 옵션을 앱에서 빠르게 다시 식별하기 어렵기 때문에 탐색 과정에서 이탈한다.

### H2 정보 연결
상품을 찾아도 오프라인 체험과 앱 리뷰·추천 정보가 연결되지 않아 구매 확신 형성이 어렵다.

### H3 혜택 비교
앱 구매 조건과 다른 채널의 조건을 쉽게 비교하기 어려워 구매를 보류한다.

### H4 구매 시점
체험은 관심을 만들지만 즉시 구매할 충분한 이유를 만들지 못한다.

### H5 대안 가설
O2O 연결보다 가격, 제품 선호, 구매 필요성 자체가 더 큰 원인이다.

## 검증 데이터

- 앱 검색어와 검색 시도 수
- 검색 결과 클릭률
- 상세 페이지 도달 시간
- 정확한 옵션 선택률
- 리뷰·혜택·재고 조회
- 찜·장바구니·구매
- 매장 방문 후 앱 행동
- 사용자 인터뷰
- 사용성 테스트

## 대안 후보

1. 매장 체험 상품 저장
2. 오프라인–온라인 연결 상품 카드
3. 최근 체험 상품 목록
4. 검색·옵션 탐색 개선
5. 상담 기록 연계
6. 혜택·재고 리마인드
7. 매장 안내 체계 개선

## 1차 해결안 후보

매장에서 체험한 상품을 사용자가 직접 저장하고, 앱에서 해당 상품의 정확한 옵션·리뷰·재고·혜택을 하나의 연결 카드로 확인하는 Flow.

## 첫 실험

5~8명의 사용자를 대상으로 매장에서 본 상품을 앱에서 다시 찾는 과제를 수행한다.

- 조건 A: 기존 검색 방식
- 조건 B: 저장된 체험 상품에서 바로 진입하는 프로토타입

측정:
- 상세 도달 성공률
- 도달 시간
- 검색 시도 수
- 정확한 옵션 선택률
- 과제 중단률
- 구매 검토 의향
- 사용자 발화
