# 01. Project Context

## 배경

사용자는 AI를 활용하면 자료 조사와 정리가 빨라지지만, AI가 만든 결과를 소비하는 방식에 익숙해질수록 자신의 사고가 충분히 외부화·구조화·내재화되지 않을 수 있다고 보았다.

이 프로젝트는 다음 문제에서 출발한다.

- 생각은 많지만 글로 꺼내기 어렵다.
- 문제, 원인, 가설, 해결책이 섞인다.
- MECE, 5Why, SCQA를 배워도 실제 문제에 적용하기 어렵다.
- AI가 만든 산출물은 남지만 사용자의 사고 과정은 남지 않는다.
- 프로젝트 결과는 있어도 왜 그렇게 판단했는지 보여주기 어렵다.
- 사고 기록이 여러 도구와 채팅에 흩어진다.
- 논리적 사고력이 실제로 개선되는지 측정하기 어렵다.

## 근본 문제

사용자에게 생각이 없는 것이 아니라, 생각을 밖으로 꺼내고 분해하고 검증하고 재구성하는 반복 가능한 사고 구조가 부족하다.

## 제품 비전

사용자가 자신의 생각을 직접 꺼내고, 논리적 사고 절차를 반복 훈련하며, 사고 과정과 결과를 데이터로 축적해 리포트·시각화·포트폴리오로 전환하는 AI 기반 학습 플랫폼.

## 장기적인 시스템 구조

### Thinking Learning System
논리적 사고와 문제해결을 반복 수행한다.

### Thinking Data System
최초 생각, 수정, 질문, 가설 변화, 판단 근거, 회고를 저장한다.

### Thinking Portfolio System
축적된 Thinking Case를 외부에 보여줄 포트폴리오로 변환한다.

## 사용자 변화

```text
막연한 관찰
→ 사실·해석 분리
→ 문제 정의
→ 문제 구조화
→ 복수 가설
→ 근거와 검증
→ 대안 비교
→ 의사결정
→ Action Plan
→ 회고
→ Case Report
→ Portfolio
```

장기 목표는 가이드가 있어야 사고하던 사용자가 반복 후에는 가이드 없이 같은 사고 흐름을 수행하는 것이다.
