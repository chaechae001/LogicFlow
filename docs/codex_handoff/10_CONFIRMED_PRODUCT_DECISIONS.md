# 현재 확정된 제품 결정

> 최신 확정 기준: 2026-08-03
> 이 문서는 과거 8단계 또는 8개 Workspace 검토안보다 우선한다.

## D1. 사고 FLOW

Thinking Flow의 학습 단계, Workspace 내비게이션, CaseStep 기준은 다음 10단계를 사용한다.

1. 목적·맥락 이해
2. 현상 관찰
3. 문제 정의
4. 문제 분해·구조화
5. 가설 설정
6. 근거 수집·검증
7. 대안 비교·의사결정
8. 해결안 설계·실행
9. 결과 평가
10. 결론 전달·회고

기존 8단계 구조는 최신 기준이 아니다. 질문이나 보조 카드는 한 화면 안에서 묶을 수 있지만, 10개 학습 단계를 8개 단계로 축약하지 않는다.

## D2. 작성 방식

각 단계에서 사용자는 다음 방식 중 하나를 선택할 수 있다.

- 자유 작성
- 구조화 입력

두 방식은 동일한 CaseStep 안에서 사용된다.

- 사용자는 작성 중 방식을 변경할 수 있다.
- 사용자는 두 방식을 함께 사용할 수 있다.
- 작성 방식을 변경해도 기존 입력은 삭제하지 않는다.
- 자유 작성과 구조화 입력의 원문 및 수정 이력은 각각 보존한다.

## D3. AI 개입

- 사용자가 먼저 작성한다.
- 사용자 작성 전에는 AI Coach를 활성화하지 않는다.
- AI는 완성 답안을 먼저 만들지 않는다.
- AI는 누락, 혼재, 논리적 공백, 반례와 추가 질문을 제공한다.
- 사용자의 작성 내용을 자동 확정하거나 덮어쓰지 않는다.

## D4. 단계 이동과 완료

- 단계 이동과 단계 완료는 분리한다.
- 미완료 단계에서도 Soft Gate 확인 후 이동할 수 있다.
- 이동만으로 단계 상태를 완료로 변경하지 않는다.
- 완료 판단은 실제 입력 기능이 구현되는 Task 05 이후 확정한다.

## D5. 데이터 보존

최소 보존 대상은 다음과 같다.

- 최초 자유 작성
- 구조화 입력
- 수정 전후 버전
- 선택한 작성 방식
- AI 피드백
- 피드백 채택·거절 기록
- 단계 checkpoint
- 단계 완료 상태

기존 append-only ResponseVersion 원칙을 유지한다.

## D6. Task 경계

### Task 04에서 다룰 범위

- 10단계 Workspace Shell
- 10단계 내비게이션과 `n/10` 진행률
- 10개 CaseStep을 수용하는 타입·상태 구조
- 자유 작성/구조화 입력 선택 UI
- 선택 전·선택 후 상태 표현
- AI Coach 활성·비활성 상태
- Soft Gate
- 단계 상태 표시
- 첫 단계 route 및 stage key 정렬
- 관련 테스트

### Task 05 이후로 미룰 범위

- 실제 자유 작성 입력과 저장
- 구조화 질문별 입력과 저장

- 자동 저장
- ResponseVersion 생성
- AI 점검 호출
- 단계 완료 판정
- 미완성 항목 안내
- 버전 비교
