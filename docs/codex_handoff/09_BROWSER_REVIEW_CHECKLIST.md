# Task 04 브라우저 직접 검수 체크리스트

## A. 진입 흐름

- [ ] `/practice`가 정상 표시된다.
- [ ] 올리브영 Practice Case 상세로 이동한다.
- [ ] 최초 생각·떠오른 해결안·의사결정 질문을 작성해 Case를 생성한다.
- [ ] 첫 Workspace가 `목적·맥락 이해` 단계로 열린다.

## B. 10단계 FLOW

- [ ] 왼쪽 내비게이션에 10개 단계가 모두 표시된다.
- [ ] 순서가 확정된 10단계와 일치한다.
- [ ] 진행률이 `n/10`으로 표시된다.
- [ ] `목적·맥락 이해`가 첫 단계다.
- [ ] `현상 관찰`과 `문제 정의`가 분리되어 있다.
- [ ] `문제 분해·구조화`가 고객 여정에만 한정되지 않는다.
- [ ] `결과 평가`가 별도 단계로 존재한다.
- [ ] `결론 전달·회고`가 마지막 단계다.

## C. 작성 방식 선택

- [ ] 각 단계에서 자유 작성과 구조화 입력을 선택할 수 있다.
- [ ] 선택 전 상태가 명확하다.
- [ ] 두 선택지 중 하나가 정답처럼 과도하게 강조되지 않는다.
- [ ] 자유 작성 선택 시 해당 상태와 설명이 표시된다.
- [ ] 구조화 입력 선택 시 해당 상태와 설명이 표시된다.
- [ ] 다른 방식으로 전환할 수 있는 미래 구조를 UI가 막지 않는다.
- [ ] 기존 입력이 삭제되지 않는다는 원칙과 충돌하는 문구가 없다.

## D. AI Coach

- [ ] 사용자 작성 전 AI Coach가 비활성이다.
- [ ] AI가 먼저 완성 답안을 제공하지 않는다는 안내가 있다.
- [ ] 작성 후 점검을 요청할 수 있다는 흐름이 이해된다.
- [ ] 실제 AI 기능이 구현된 것처럼 오해시키지 않는다.

## E. 단계 이동과 Soft Gate

- [ ] 미완료 단계에서 앞으로 이동하면 Soft Gate가 표시된다.
- [ ] Soft Gate 후에도 사용자가 계속 이동할 수 있다.
- [ ] 이동만으로 단계가 완료 처리되지 않는다.
- [ ] 이전 단계 이동이 정상 작동한다.

## F. Case 시작 기록

- [ ] 내 첫 생각, 떠오른 해결안, 의사결정 질문을 다시 확인할 수 있다.
- [ ] 긴 내용이 지나치게 잘리거나 읽기 어려운 좁은 카드에 갇히지 않는다.
- [ ] 현재 단계 작성 영역과 시각적으로 혼동되지 않는다.

## G. 상태와 예외

- [ ] 저장 상태 표시가 정상이다.
- [ ] 로딩 상태가 정상이다.
- [ ] Case 없음 상태가 정상이다.
- [ ] Repository 오류 상태가 정상이다.
- [ ] 새로고침 후 예상한 화면으로 복원된다.

## H. 반응형

- [ ] 데스크톱에서 3열 구조가 읽기 쉽다.
- [ ] 좁은 화면에서 10단계 내비게이션과 작성 방식 선택이 깨지지 않는다.
- [ ] AI Panel과 중앙 작성 영역이 겹치지 않는다.

## I. 범위 확인

- [ ] 실제 자유 작성 저장 기능은 아직 없다.
- [ ] 실제 구조화 질문 입력 저장 기능은 아직 없다.
- [ ] 실제 AI 호출은 없다.
- [ ] Task 05 기능이 선행 구현되지 않았다.
